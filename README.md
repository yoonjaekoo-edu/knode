# KNODE

**Find the path.**

KNODE is a Wikipedia navigation game. Choose two articles, then reach the target using only links inside the current article.

## MVP

- Korean Wikipedia
- Start and target article validation
- Wikipedia article rendering
- Internal-link-only navigation
- Move counter and timer
- Full path history
- Completion screen
- Responsive UI
